## v0.7.3 · 左右划切页 + 玻璃加深

两个变化：**四个 Tab 页能左右划了**（划动跟手、松手弹簧落位、状态不丢），**功能层玻璃加深一档**（白 tint 2% → 6%、rim 1px → 2px）、首页顶部加一层柔和色洗。

行为一行没动：500ms、答对直走、Leitner、中英搜索、遮盖、排序、弹簧 / 按压 / 触点高光 / 抖动 / 对勾、正文纸面卡、字色对比，全部照旧。

### 一、左右划切页

- 外壳从 `IndexedStack` 换成 `PageView` + `PageController`。左右划切换，点 Tab 也能切，两边同步。
- **划动跟手**：手指动多少页面动多少；**过半才翻页**，不到一半弹回原页。
- **落位用全 App 那条弹簧**（mass 0.8 / stiffness 300 / damping 24），不是默认的 `PageScrollPhysics`（mass 0.5 / stiffness 100），也不是线性动画。点 Tab 滑过去走同一条弹簧。
- **选中态跟着走**：划动过半 Tab 栏就换高亮；点 Tab 时选中态立刻跟上，不等动画。
- **震动只在落定**：滑到整页时震一次 `lightImpact`（与答对同款）。划动过程中不震；点 Tab 也不再「按下就震」，改成落定那一下，全程只有一次。点当前页、或者拖一点点又弹回原页，不震。
- **状态不丢**：四个页面各带 `AutomaticKeepAliveClientMixin`。划走再划回来，滚动位置、学习进度、搜索框内容、遮盖状态都在，**不重新读库**。
- **只认横向划**：词库列表的上下滑不受影响；学习会话页、详情页是 push 出来的整页，不参与左右划。

### 二、玻璃加深

| 项 | 之前 | 现在 |
| --- | --- | --- |
| 白 tint（Tab 栏、按钮、单词框、选项） | 2% | **6%** |
| 迎光 rim 线宽 | 1px | **2px** |
| 选中态白 tint | 36% | 36%（不变） |
| 点错态粉 | `#FF2E7E` 22% | 22%（不变） |
| 磨砂 | 1.5px | 1.5px（不变） |

按 2026 版 HIG 的做法：tint 更重、rim 更可见。v0.6.9 把玻璃洗到几乎只剩一道边，纸底上一屏七块玻璃在真机上看不出是玻璃；这一版回调一档，玻璃终于有「一层水膜」的重量。

### 三、首页色洗

- 首页顶部 420px 铺一层五色柔和色洗（8%–12%，上下两端渐隐），让首页的玻璃背后有东西可弯。
- 五色横向分开、互不重叠 —— 叠在一起每团就算只有 10%，五层也会糊成一块灰紫。
- 实际露出来的是任务卡下沿到两个玻璃按钮这一带（卡是不透明纸面卡，会盖住上半段），正好是首页唯一有玻璃的地方。
- **词库页、我的页不加**，保持干净纸面；纯装饰层不吃点击、不随列表滚动。

### 装机先看这几处

1. **划动跟手程度**：手指动多少页面动多少；松手后是弹簧滑到整页，不是匀速。划过一半松手就到下一页，不到一半弹回。
2. **点 Tab 的手感**：页面滑过去 + 选中态立刻亮，震动在落定那一刻（不是按下那一刻）。扫到第 4 个 Tab 也走弹簧，落位时有约 2% 的过冲回弹。
3. **震动合不合适**：与答对同力度（`lightImpact`）。嫌频繁只能改「只在换页落定时震」这条规则，力度别单独调。
4. **首页玻璃有没有「东西」**：两个胶囊背后现在有淡淡的五色，主操作那颗最明显。嫌淡就把色洗透明度往上推（8–12% 那条线的上限），别再加投影。
5. **Tab 栏 6% 的 tint**：条子比原来白一档，字仍然压在玻璃上。若觉得「白块」太重，回调到 4% 即可，rim 别跟着减。

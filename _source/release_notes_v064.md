## v0.6.4 预览版：液态玻璃一屏 + 两个功能

**还是预览版，只改了学习卡片这一屏的视觉。** 词库、详情、我的、Tab 外壳、全局主题都没动。
装上看效果，看完再决定要不要全量换、要不要做真折射。

### 功能（一）

**从学习会话进详情页，中文直接显示，不遮盖。**

- 三种情况都算：点「不认识」、答错之后选对、新词答对。
- 从词库列表进详情仍按全局「遮盖中文」开关走，没变。
- 实现上给详情页加了 `revealChinese` 参数，学习会话进去传 true，词库进去不传。
- 这一种入口下把详情页右上角的遮盖开关收起来了 —— 那个开关是全局的，
  摆在这里点了会把词库页也一起改掉，容易误伤。

### 功能（二）

**每张卡片出现时自动读一遍单词。**

- 新词、复习、当日重测都读；第一张也读。
- 一张卡只读一次：从详情页回来、转屏、页面重建都不重读。
- 手动点「发音」仍可随时再读。
- 手机没装英文发音引擎时静默跳过，不弹提示（自动读是附加动作，不该打断学习）。

### 液态玻璃（只这一屏）

风格按 guanmo-ai/design-style 的 014 液态玻璃来，不是 2020 年那种「大半径模糊 + 白边」的毛玻璃。

- 页面底色换成风格里的墨 `#0B0C10`，底下一层低透明度彩色光（橙/粉/薄荷/紫/蓝）——
  玻璃后面得有东西可弯，才看得出是玻璃。
- 玻璃只做在控件层：**发音按钮、不认识按钮、2×2 选项格**，bevel 26px。
  单词区块是正文卡片，保持不透明普通卡片，不参与玻璃。
- 玻璃本身不上色，只有三样：白 tint 5%、迎光侧（左上 -37°）1px 亮边、
  投影 `0 10px 32px rgb(0 0 0 / .18)`。
- 选中态：白 tint 加深到 36%，亮边更亮，不另挑颜色。
- 点错态：`#FF2E7E` 的 tint。
- 玻璃上的中文一律 NotoSansSC 700、字号 ≥16px（选项释义 16/700）。
- 选项格间距仍是原来的 10px（风格建议 ≥24px，否则相邻玻璃会融成一块）——
  这版先保持原样，融不融看一眼再定。

### 必须说清楚的一件事

**这版是近似效果，没有做真折射。**

- 做了：半透明 + 背景模糊（≤6px 磨砂）+ 方向性高光 + 投影。
- 没做：边缘位移（背景在玻璃边缘被推开、放大）和 6% 色散（边缘细微彩边）——
  这两样是液态玻璃和普通毛玻璃的真正区别，需要写 shader，不在这一版。
- 所以看起来会是「一块有厚度感的玻璃压在彩色光上」，但凑近看边缘不会有折射拉伸。

### 没动的

  「不认识」记错与进详情、Leitner 调度、当日重测 —— 全与 v0.6.2 一致。

- 全局主题、Tab 外壳、词库、详情（视觉）、我的 —— 零改动。

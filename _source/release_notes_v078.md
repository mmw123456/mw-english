# v0.7.8 首页主角化

首页原来各区块同圆角、同纸面、同灰字：进度环、热力图、色带、两个按钮视觉权重差不多，眼睛不知道先看哪。这一版只改首页，把「今日学习 + 开始学习」立成唯一主角，其余全退后。逻辑与数据一行没动。

## 一、Hero：环更大 + 一行今日状态

进度环 132 → **176**，线宽 12 → **14**，环里的数字 44pt → **56pt**（`/30` 仍是小字）。动效没变，还是全 App 那条弹簧（300 / 24 / 0.8），数值变了就从旧值接着扫，不从 0 重播。

环下多一行 14pt、墨 70% 的今日状态，直说「今天还差多少」：

| 状态 | 文案 |
|---|---|
| 未开始 | 今天还没开始 · 目标 N 词 |
| 进行中 | 今日已学 X / N，还差 M 词 |
| 完成 | 今日目标完成 |

N 是当日新词目标，跟断档削减一起走（断档那天会是「目标 6 词」，不是写死的 30）。三格统计（新词 / 待复习 / 答错）没动。

## 二、CTA：一个玻璃主按钮 + 一个文字入口

「开始学习」变成 Hero 主按钮：全宽、56 高、橙 tint 10% 的玻璃胶囊、18pt w700。它现在是首页唯一一块玻璃。

「只复习」从第二个玻璃胶囊降成一行文字按钮（墨 70% / 16pt），放在主按钮下面。文案与跳转一行没动：0 个待复习时仍然写「没有待复习」且不可点。

## 三、层级：区块标题退到第二层

「学习足迹」「怎么排的」统一 16pt w700 墨——比正文重、比 Hero 的 56 小得多。热力图、色带、卡片内容、间距（12 / 20 / 32）、圆角（18）全部没动。

## 没动的地方

不新增颜色、不新增玻璃、不动氛围洗。Leitner、每日 30、按天日志、shader、玻璃常量、Tab 栏、热力图格子、色带、词库、详情、会话页——全部零改动。

## 装哪个

- `app-arm64-v8a-release.apk` — 绝大多数手机，选这个
- `app-armeabi-v7a-release.apk` — 老的 32 位机
- `app-x86_64-release.apk` — 模拟器

`versionName 0.7.8` / `versionCode 2023`，minSdk 24，targetSdk 36。

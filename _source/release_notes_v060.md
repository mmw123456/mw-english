## v0.6.0 学习交互改四选一

学卡片从「认词 + 三题型 + 自评」改成统一的百词斩式四选一。**Leitner 调度规则一条没动**。

### 卡片

- 上面：单词、音标、发音按钮。下面：四个中文意思。
- 新词、复习、当日重测同一套，不再有题型轮换和自评。
- 点对：选项变绿打勾，500ms 后自动走。
- 点错：该选项变红禁用，留在本卡继续选，答对前不揭示正确答案。
- **首次答错即记错**（降一箱、进当日重测），之后继续选对不再改判，也不会重复记流水。

### 干扰项

- 优先取形近词（编辑距离 ≤3，和详情页同一套算法）的第一条中文释义。
- 不够 3 个，用同批 820 词补，再不够用同首字母 / 全库随机兜底。
- 正确项只出现一次，四个位置每次现洗；重测卡回库重建选项，不沿用上一张的位置。
- 三条硬过滤：带英文的释义（「xx 的过去式」等于送答案）、与正确释义同义的写法、空串与重复。

实测 820 词全部凑得齐 4 个选项，其中 743 词（90.6%）三个干扰项都来自形近词。

### 答完之后

- 新词答对 → 自动进词条详情整页。
- 复习词第一次就答对 → 直接下一张；答错过再选对 → 进详情页。
- 详情页底部有「下一个」，上滑也能走；按系统返回键退出同样进下一张，不会卡在已答完的卡上。

### 其他

- 会话小结改为：新词 / 复习 / 首次答对 / 首次答错 / 正确率。
- 例句这版不做，卡片上不显示。

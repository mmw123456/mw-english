# v0.7.9 字重对比拉开

首页的字号层级已经有了（56 / 16 / 14），但字重没拉开：标题、正文、次要字很多处挤在 500 / 600。包里只打包了思源黑体 Regular 400 和 Bold 700 两个字重，500 / 600 会被字体回退成 400 —— 等于标题和正文一样细，眼睛分不出主次。

这一版只动 `fontWeight`，外加把 T4 次要字统一到墨 62%。字号、间距、圆角、布局、Leitner、每日 30、按天日志、shader、玻璃常量、Tab 栏、热力图、色带、词库、详情、会话页的数据与行为全部没动。

## 四档

| 档 | 用在哪 | 字重 | 颜色 |
|---|---|---|---|
| T1 主角数字 | 环内数字、今日新词、三格统计 | 700 | 墨 |
| T2 标题 | 区块标题、单词、按钮文字 | 700 | 墨 / 62% |
| T3 正文 | 释义、说明文字、状态行 | 400 | 墨 70% |
| T4 次要 | 时间、备注、计数小字、`/N` | 400 | 墨 62% |

## 改了哪些

- **主题字阶**：`bodyLarge` / `bodyMedium` 500 → 400；`labelMedium` / `labelSmall` 600 → 400。其余标题与按钮本来就是 700，一行没动。
- **区块标题补 700**：词库「词表」、三个分组标题、我的页三个分组标题、详情页「单词本原文 / 词典补全 / 单词变形 / 前后缀分析 / 近义词 / 形近词」、详情页「发音」、首页「只复习」。
- **T4 统一墨 62%**：今日新词、AppBar 第 N 天、色带图例、热力图说明、详情页 `#序号 / 自加 / 词典` 标签、普通状态胶囊。
- **例外**：箱位徽章仍用墨色（压在 15% 箱色底上，62% 会糊，决策 96 优先）；徽章字重按 T4 降到 400。

全 App 现在只剩 `w400` / `w700` 两个字重，`w300` / `w500` / `w600` / `w900` 一个都没有。analyze 0 issue，测试 192 passed，新增 15 条四档字重断言。

## 没动的地方

不新增颜色（只把 T4 的 70% 归一档到已有的 62%）、不新增玻璃、不动字号的任何一处。Leitner、每日 30、`daily_stat`、shader、玻璃常量、Tab 栏、热力图格子与蓝阶、六箱色带、词库搜索 / 排序 / 遮盖、详情与会话页的流程与数据全部零改动。

## 装哪个

- `app-arm64-v8a-release.apk` — 绝大多数手机，选这个（versionCode **2024**）
- `app-armeabi-v7a-release.apk` — 老的 32 位机（versionCode **1024**）
- `app-x86_64-release.apk` — 模拟器（versionCode **4024**）

`versionName 0.7.9`，minSdk 24，targetSdk 36。三份 APK 的 versionCode 不同是 Flutter 分包自动加的 `1000 × ABI 码`（arm64 +2000、v7a +1000、x86_64 +4000），不是 bug，也不许强制统一。

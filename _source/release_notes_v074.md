# v0.7.4 首页进度环 + 学习热力图

首页从「一条细进度条」变成「一个环 + 一块足迹」，数据第一次在首页有了形状。

## 进度环（替换任务卡里的细进度条）

- 直径 132、线宽 12、圆头端点；轨道墨 10%，填充蓝 `#2E4BFF`（纸上 5.26:1）。
- 环里是今天的数字：已学多少（44pt 粗体）+ `/ 目标`（小字）。
- 比例 = 今日新词已学 ÷ **今日目标**，和环里的数字同一份数据。断档削减配额时，顶部写「目标 6 词」、环里就是「/ 6」，不会自相矛盾。
- 动效走全 App 那条弹簧（300 / 24 / 0.8）：首次出现从 0 扫到当前值，数值变了从旧值接着扫，不从 0 重播。
- 卡片顶部那对标签、下面三格数字（新词 / 待复习 / 答错）原样保留。

## 学习足迹（首页最下面，三张数字卡之后）

- GitHub 式网格：最近 12 周 × 7 天，列是自然周（周一开头），一格一天。
- 右上角「连续 N 天」：连续有学习记录的天数；今天还没学就从昨天往回数，断一天归零。
- 点一格，下面一行小字显示那天：「11月25日 · 学了 28 词」/「11月20日 · 没学」。
- 单色阶：没学 = 纸面卡底 + 0.5px 描边；1–9 词 25%、10–19 词 50%、20–29 词 75%、30+ 词 100%。当日完成量 = 新词 + 复习完成数。
- 未来那几天不画（不是涂成「没学」），留白比涂灰更不会骗人。
- 区块本身是纸面卡，不是玻璃——内容层不上玻璃，这是全 App 的规则。

## 按天日志（这次之后才有历史）

新增 `daily_stat` 表：`(day, word_key)` 做主键，答对才算完成一个词，一天一个词只记一次。当日重测、先错后对都不会把数字抬高；已记下的天不许被后来的作答改写。

**从这一版起攒，不补历史。** 升级当天热力图几乎全白、连续天数是 0，这是刻意的：`study_log` 里虽然有每次作答的流水，但推不出当时那条是「新词」还是「复习」，回填出来的是另一个口径。

## v0.5.0 · 学习卡片 + 三题型 + Leitner 调度

这一步开始真正写学习记录 —— 之前 `study_record` 只有星标在写，现在箱位、到期、答题流水都跑起来了。

### 怎么学

- **新词先认一遍**：新词第一次出「认词卡」—— 单词、音标、发音、两段释义，看一遍点「记住了 / 不认识」，不考
- **三题型轮换**：英 → 中（四个中文义项选一个）、中 → 英（给中文选单词）、主动回忆（只给单词，自评想没想起来）
- 同一个词每次复习换一种问法，按 `(词哈希 + 已答次数) % 3` 轮换
- 答完立刻给对错 + 正确释义 + 词典补全，可点「看词条详情 →」进 v0.4.0 的整页详情（没有另写一套）

### 调度（6 箱 Leitner）

- 箱位 0 = 新词，1–6 箱的间隔是 **1 / 2 / 4 / 7 / 15 / 30 天**
- 答对升一箱；答错降一箱，**不归零**
- **熟词保护**：到过 4 箱以上的词，答错最低只落到 3 箱，之后再错也停在 3 箱（防一次手滑打回低箱重学）
- **新词门槛**：连续答对 3 次才允许进 3 箱以上
- **当天答错当天再考一次**：重测过关只回箱、不额外升箱，所以一次错就只亏一箱
- **新词当天收尾复习**：当天新学的词学完后再考一遍，不等明天
- **断档**：3 天以上新词减半、复习排前面；7 天以上按断档天数摊薄（最低 3 个）
- **积压上限**：单日复习最多 150 词，多出来的顺延到明天（自然排队，不另写逻辑）

### 学习页

- `0 / 30` 读真实记录，不再写死；配额被断档削减时会显示提示条
- 多一个「只复习待复习 N 词」入口
- 底部写清六箱怎么排的

### 工程

- 数据库 schema 2 → 3：`study_record` 加 `started` / `retest` / `peak_box`，老库走 `ALTER TABLE`，学习记录不丢
- 修一个 v0.4.0 的隐性 bug：以前点个星标就会插一条 `box = 0` 的记录，被算成「今天学过」。现在星标不算学过，只有真答题才算
- 当日配额存 `settings.quota_YYYY-MM-DD`，当天不重算（否则断档配额会中途跳回 30）
- 作答在**一个事务**里同时写记录和流水，中途杀进程不会记错账
- `flutter analyze` 0 issue，`flutter test` 30 passed（新增 21 个调度规则单测）

### 安装

- `app-arm64-v8a-release.apk`（45.8 MB）— 大多数手机用这个
- `app-armeabi-v7a-release.apk`（43.5 MB）— 老 32 位设备
- `app-x86_64-release.apk`（47.0 MB）— 模拟器

> 签名仍是 Android Debug 证书，可直接安装；换机器后无法覆盖升级（需先卸载）。

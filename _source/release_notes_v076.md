# v0.7.6 细节打磨（字体、间距、动效）+ 修热力图今天格

不加功能、不动颜色，只打磨三处细节，外加修一个截图里发现的问题。

## 修：今天格不再实心黑

上一版今天那格在截图里是**实心黑**。热力图的读法是「越深学得越多」，实心黑会被看成「今天学得最多」，跟「今天、还没学」正好反了。

根因不在描边，是描边的画法：上一版用了一条**实心墨投影**（boxShadow）当描边，而格子的底色是半透明的（空格墨 5%、蓝阶 25–100% 都带透明度），投影从背后透上来，把整格涂黑。顺手也修掉了点任意历史格的同一个毛病。

现在：今天格底色跟空格一样（墨 5%），只多一圈 1.5px 墨 60% 描边；选中的格子也只加一圈边，不再往背后垫实心块。

## 数字用等宽

所有关键数字改等宽（tabular figures），数字变化时宽度不再左右跳：环里的「13」与「/ 30」、三格（新词 / 待复习 / 答错）、首页三张卡、词库两张卡、词表序号。

没换字体，也没加字体文件——用的就是已打包的思源黑体的 `tnum` 特性。

## 环内数字滚动递增

数字从旧值滚到新值，跟环用**同一根弹簧**（300 / 24 / 0.8），不另加曲线。过冲时显示的整数会被夹在终点以内，不会短暂闪出一个比目标更大的数。

首次进页面不从 0 播——切 Tab 回来、下拉刷新都只显示当前值，只有数字真的变了才滚。

## 首页两按钮补按压缩放

「开始学习」「只复习」按下 90ms 收到 0.96，松开弹回，跟学习卡上的选项同款。禁用态不缩。

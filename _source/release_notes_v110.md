## v0.11.0 统一查词

查词以前散在三处：词库页自己拼三条 SQL 只做列表过滤、文章页自带一套弹层、学习页只能进当前词的详情页。这一版收成一套，四个入口都调它，查词**不占新 Tab**。

### 四个入口

| 入口 | 怎么用 |
| --- | --- |
| 学习页（首页） | AppBar 右侧放大镜 |
| 词库页 | 顶部搜索框（原位原样），结果仍按「我的词表 / 自加词 / 离线词典」三段分组 |
| 学习会话 | 单词卡右上角放大镜 —— 不记答题、不动当前卡片；顶栏书本图标仍进当前词完整词条 |
| 文章详情 | 双击正文里的词；有精确命中直接弹卡，只有候选时进查词页 |

### 释义从哪来（优先级写死）

1. **820 词**：两段式 —— 词书原释 + ECDICT 全释，两段不一样才分开标。
2. **自加 / 导入词**：入库时存下的释义。
3. **ECDICT 离线词库（43,350 词）**：兜底。

查不到就写「未查到」，不编释义、不联网、不调 AI。

### 搜索规则

- 英文单词与短语按整串前缀匹配（`once (and) for all` 这种带括号的也能搜到），中文按释义包含匹配。
- 大小写不敏感，候选最多 10 条；输入就是个词条时直接出结果，不用再点一次。
- 输入规范化只压空白、转小写，**不动括号与连字符**。

### 结果卡

词 / 音标 / 词性 / 来源 / 释义 / 发音（系统 TTS，与学习页同一套）/ 加入生词本 / 查看完整词条。

- 「加入生词本」按自加词口径：同一套六箱、0 箱起步、占每日新词配额；写库时把释义一起存下，避免「词在库里但释义丢了」。
- 已在库时按钮显示「已在词库 · 箱 X」并置灰，不重复加。

### 本版不做

每词例句、读后填空、拼写、统计图表、查词历史。

# v0.7.5 首页暖冷分工配色

只改首页配色，不动结构、不动行为。

## 进度环改暖橙

- 填充从宝蓝 `#2E4BFF` 换成深一档橙 `#E8490F`。纸上对比 3.48:1，12px 的环线达到图形元素 3:1 的线。
- 没有用那支亮橙 `#FF5A1F`：它在纸上只有 2.78:1，环会糊进纸里。
- 直径 132 / 线宽 12 / 圆头 / 轨道墨 10% / 弹簧动效——一个都没动。环里的数字仍是墨色。
- 蓝没有删，只从环上退下来：热力图那套蓝阶原样保留。

## 开始学习按钮带橙 tint

- 「开始学习」的玻璃 tint 改成橙 10%，跟环呼应；文字仍是墨色。
- 「只复习」保持原来的白 tint（6%），不上色。两个按钮现在既靠深浅、也靠色温分主次。

## 热力图空态三件

- **空格子**：底色从纸面卡改成墨 5%，边框保留。以前空格和卡片同色，远看像没加载出来。
- **全空时**：标题下多一行「从今天开始记」。有一格填上就消失。
- **今天那格**：加 1.5px 墨 60% 描边，跟历史格区分开。描边画在前景，不占布局、不缩色块。

蓝阶四档（25 / 50 / 75 / 100%）、12 列 × 7 行、周一开头、月份小字、点格出当日数据——全没动。

## 顺带核了「最右列被切」

四档屏宽（320 / 360 / 390 / 414）逐档量过：12 列 × 格子 + 11 个 4px 间距都落在卡片内宽里，左右各留 20px 内边距，没有溢出。截图里像被切，大概是本周最右列只画到周四（周五到周日还没到、按设计不画），下面空着。

不过查出一个隐患：原来格子尺寸有 12px 硬下限，容器特别窄时（分屏、系统显示缩放）12 列的总宽会顶出卡片，最右列就真的被切。现在改成向下取整到 0.1px，宁可格子小一点，也不让 12 列缺列。正常屏宽下格子只差不到 0.1px，看不出来。

## 没动的地方

学习会话页、详情页、shader、玻璃常量、Leitner、按天日志、Tab 栏、环的尺寸与动效、热力图蓝阶、词库 / 阅读 / 我的页——一行没改。

- `app-armeabi-v7a-release.apk` — 老的 32 位机
- `app-x86_64-release.apk` — 模拟器

`versionName 0.7.5` / `versionCode 2020`，minSdk 24，targetSdk 36。

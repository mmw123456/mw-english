## v0.6.6 预览版：单词框玻璃 + 答对直走 + 动效换成弹簧

**还是只改学习卡片这一屏。** 词库、详情、我的、Tab 外壳、全局主题都没动。

### 一、单词框换成玻璃

- 单词 + 音标那张卡，从「不透明深色卡片」改成玻璃，参数跟选项玻璃同一套：
  白 tint 5%、左上 1px 迎光亮边、投影 `0 10px 32px /.18`、圆角 26。
- **中间是平的，只弯边缘**：文字画在平坦的 tint 上，没有任何位移或折射拉伸，
  36pt 单词和音标都不会被折碎；音标落在中央平坦区。
- 氛围渐变能透过这层玻璃看到一点 —— 这是它跟深色卡片的区别，也是玻璃有东西可弯的前提。
- 发音按钮仍在卡片外面（压在卡片里就没有背景可弯了）。

**仍是近似效果**：做了半透明 + ≤6px 背景模糊 + 方向性高光 + 投影，
没做真折射（边缘位移 + 色散要 shader），跟 v0.6.4 的选项玻璃同一套做法。

### 二、答对流程变了

- **第一次点对（新词、复习都算）→ 500ms 后直接进下一张卡，不再进详情页。**
- 只有「先点错、再选对」才进详情页 —— 那才是真的需要看完整释义的时候。
- 「不认识」仍直接进详情页，没变。
- 代价说明：新词第一次答对不再自动给你看完整释义/变形/近义词；
  想看就从词库点进去，或点「不认识」。

### 三、交互变灵动（全部走弹簧）

- 弹簧统一用 mass 0.8 / stiffness 300 / damping 24（阻尼比约 0.72，轻微过冲）。
  入场、按压回弹、选中都是这一条，没有线性动画。
- **按压**：按下 90ms 内缩到 0.96，玻璃朝手指方向微倾，同时长大一点点；
  松手弹簧回弹。
- **触点高光**：按下的位置亮一团白光，跟手指走；松手 200ms 内淡出。
- **选中**：放大到 1.03 + 对勾用 300ms 画出来；白 tint 36% 不变。
- **点错**：左右抖 360ms（约 3.5 个来回，幅度衰减），**抖完才变粉禁用**，
  不是啪一下只变色。
- **入场 stagger**：新卡切入时单词 0ms，四个选项 50 / 85 / 120 / 155ms，
  「不认识」190ms，各自独立弹簧。
- **触觉**：点选项给轻触觉，答错换成中档；没触觉马达的设备由系统静默忽略。
- 性能红线：全部只动 transform / opacity，不改宽高和位置；
  点按反馈 90–200ms，不拖 500ms 自动走的节奏。

## v0.13.0 听音拼写

学习 Tab 多了一颗「拼写练习」：听一遍词，把它拼出来。拼完一轮给小结，错词可以点进去看词条。

**拼写只是独立练习** —— 不升箱、不降箱、不动 streak、不动每日进度。

### 入口与一轮

| | |
| --- | --- |
| 入口 | 学习 Tab（首页）「只复习」下面一行「拼写练习 · 今天 N 词」，**没占新 Tab** |
| 今天没词 | 按钮置灰，直接写「今天没词可拼」，点不进去 |
| 一轮的题 | 今天的词：今天新词 + 今天到期的复习词，跟学习会话同一套词表 |
| 题数上限 | = 每日目标（默认 30，设置里调小跟着小） |
| 顺序 | 今天已学的新词 → 今天还没学的新词 → 今天到期的复习词 |

### 每题

1. 进题自动用系统 TTS 读一遍（与学习页同一套）。喇叭随时能点，**重听不限次数、不扣分**。
2. 在输入框拼写，点「提交」或按回车判对错，结果立刻出来。
3. **判对**：显示「对了」+ 正确拼写，1 秒后自动进下一题，也能点「下一题」提前走。
4. **判错**：当场给正确拼写 + 音标 + 中文释义，并留着你拼的那一版做对照（「你拼的是 xxx」）。**不自动跳**，点「下一题」再走。

### 判定规矩（写死）

- 大小写不敏感，首尾空格不算，中间多个空格算一个。
- 短语整串拼，不拆词：`take` 不算对 `take advantage of`。
- `once (and) for all` 的 `(and)` 可有可无：`once for all`、`once and for all`、`once (and) for all` 都算对。
- 空着不填算错。

### 一轮小结

- 对了几题 / 共几题、正确率。
- 错词清单：每条「错拼 → 正确拼写 + 音标 + 释义」，点一条进词条详情页。
- 底部可以「再拼一轮」或「返回学习」。

### 正确率

- 本地存一张 `spelling_round` 表（日期 / 题数 / 对数），一轮一行，半途退出不记。
- 拼写页顶部只有一行累计正确率（`累计正确率 87% · 32 轮 480 题`）；一题都没拼时写「还没有拼写记录」，不显示 0%。
- 不做图表、不做学习统计页 —— 那是下一版的事。

### 本版不做

拼写影响六箱、语境填空、例句朗读、学习统计页 —— 一律不做。

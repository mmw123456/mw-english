## v0.10.0 · 阅读与文章生成

阅读 Tab 从占位变成真功能：按你自己的词库，一篇一篇生成 25 个目标词的英文短文。

### 怎么用

1. **我的 → 设置 → 阅读**，填 DeepSeek API Key（加密存在本机）。
2. 进 **阅读** Tab，点 **生成下一篇**。
3. 生成完自动进详情页：正文里目标词加粗，**双击任意单词**查意思与音标（查离线词典，不联网），查到的词可一键进生词本。
4. 底部可以朗读全文（播放 / 暂停 / 停止），也可以单独点某个词的喇叭发音。

### 生成规矩（写死，不可调）

- 每篇 **25 个目标词**、正文 **350–500 词**、CET-4 水平
- 每个目标词在正文里只出现一次并加粗，用原形
- 生词率 2–5%（除这 25 个词之外的生僻词占比）
- 生成后自检四项，不过就带原因重写一次；还不过就报错，**不把坏文章塞进列表**

### 词是怎么挑的

820 词按顺序走，跳过**已斩**的、**已掌握**的（箱位 ≥5 或连对 ≥3）、**已经当过目标词**的。不够 25 个时依次回填：820 已掌握的 → 自加 / 导入词 → 自加词已掌握的。还不足就直说「能用的词只剩 N 个」，不硬凑。

所以进度是自动往前推的，不会重复出同一批词。

### 边界

- **只有你点「生成下一篇」才联网，一次一篇**，不会自动批量生成（按量付费）。
- 没填 Key：直接提示先去设置，不发请求。
- 没网 / 接口报错：已生成的文章照常读，双击查词照常用，只在生成那一步给一句人话。
- 文章全部存在本机 SQLite，断网也能打开。

### 本版变更

- **新增 `INTERNET` 权限**：只为调 DeepSeek。学习数据（词库、学习记录、文章、Key）仍然只存本机、不上传。v0.9.0 及之前是纯离线 App。
- 数据库升到 schema 6：新增 `article` / `article_word` 两张表，老数据不动。
- 设置页新增「阅读」分组（DeepSeek Key）。

### 本版不做

读后填空小测、每词 2–3 条例句、拼写、统计图表 —— 一律不做。

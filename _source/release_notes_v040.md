## v0.4.0 · 词条详情整页

从词库列表、搜索结果、近义词、形近词都能点进**整页详情**（原来的底部弹窗已删）。

### 详情页

- **头部**：单词、音标、发音按钮（系统离线 TTS）、星标
- **释义两段并列**：上段「单词本原文」、下段「词典补全」，PDF 里被「…」截断的单独提示
- **单词变形**：解析 `words.exchange`，过去式 / 过去分词 / 现在分词 / 三单 / 复数 / 比较级 / 最高级，有才显示（688/820 词有）
- **前后缀分析**：513 条精确白名单，命中才显示拆解与词源说明；没命中整块不出现，**不再用规则硬拆**
- **近义词**：820 词专属，814 词有（2463 条），每词 2–4 个并配一句辨析；词典里的其他词不做，没有就整块不显示
- **形近词**：43,350 词里按编辑距离取最像的 3–5 个，已排除派生词（`eliminate → eliminated` 这种不出现）

### 词库页

- **遮盖中文**：右上角开关，默认关；打开后中文释义遮住，点一下才显示，状态存本地
- **排序切换**：顶部「原序 / 随机」，点一次重新洗一次，不改数据库顺序
- **加入我的词表**：词典里的词可加入，列表里标「自加」、可移除；820 词内的显示「已在词表」

### 工程

- 项目真身迁到 `D:\ai-projects\mw-english`（纯英文路径），`build_release.sh` 去掉同步段，直接构建
- 数据库 schema 升到 2，新增 `synonyms` / `user_added_words` 两张表
- `flutter analyze` 0 issue，`flutter test` 9 passed

### 安装

- `app-arm64-v8a-release.apk`（45.7 MB）— 大多数手机用这个
- `app-armeabi-v7a-release.apk`（43.5 MB）— 老 32 位设备
- `app-x86_64-release.apk`（46.9 MB）— 模拟器

> 签名仍是 Android Debug 证书，可直接安装；换机器后无法覆盖升级（需先卸载）。

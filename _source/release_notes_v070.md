## v0.7.0 正式版 · 全 App 换浅色纸底液态玻璃

学习卡片页的预览到此定稿：**整站只剩一套主题**（纸底 + 玻璃，浅色）。深色主题作废，M3 预览主题删除。

行为一行没动：2×2 选项、答对直走、500ms、Leitner、中英搜索、遮盖、排序、弹簧 / 按压 / 触点高光 / 抖动 / 对勾 / stagger / 触觉，全部照旧。

### 一、主题合并

- `AppTheme.dark` 删掉，只剩 `AppTheme.light`：纸 `#F3F2EE`、墨 `#0B0C10`、次要墨 70%、三级墨 62%、氛围五色、玻璃参数（磨砂 1.5px、白 tint 2%、投影 `.20` / 选中 `.28`、迎光 1px 亮边）。
- `liquid_glass_preview_theme.dart` 改名 `liquid_glass.dart`，预览专用的那套 `ThemeData` 并进全局主题；页面不再各自 `Theme(data:)` 局部覆盖。
- M3 预览主题 `study_preview_theme.dart` 与它的专属测试删除 —— 比较结束，不留死代码。
- 深色不留切换入口（本来也没有）。

### 二、玻璃与纸面卡的分工

| 用在哪 | 用什么 |
| --- | --- |
| 控件：按钮胶囊、搜索框、Tab 栏、星标、发音、单词框、选项 | **玻璃**（`GlassSurface`） |

### 三、逐页

- **首页**：底换纸；任务卡与三张数字卡换纸面卡；「开始学习」「只复习」换全宽玻璃胶囊，主操作 tint 10%、次操作 2%，靠深浅分主次，不引第二个颜色；六箱说明走墨 / 次要墨。
- **词库**：底换纸；列表行保持不透明（压纸）；搜索框换玻璃胶囊；排序、遮盖、星标逻辑没碰。
- **详情**：底换纸；释义、变形、前后缀、近义词、形近词各区块换纸面卡；星标（圆形玻璃，48 点击区）、发音、「加进我的词表」换玻璃；`revealChinese` 与遮盖逻辑没碰。
- **我的 / 阅读**：底换纸，卡片补 0.5px 描边，字色跟着纸走。
- **Tab 栏**：换成悬浮玻璃条（四周留 16、底下留 10、28 圆角、投影 `.20`）。内容从条子底下穿过去（`extendBody`），玻璃才有东西可弯；图标与文字都用墨色，选中项在条子里再压 36% 白 tint。
- **氛围渐变**：只留在学习卡片页。其余页纯纸底。

### 装机先看这几处

1. **白纸上的玻璃很淡**：胶囊按钮几乎只剩一层投影和一道斜光，这是 Clear 玻璃在浅色底上的正常样子。
2. **Tab 栏压着内容**：滚动时字会从玻璃底下经过，带 1.5px 磨砂和一层柔影 —— 觉得脏就把条子的 `blur` 改 0。
3. **词库列表没有分隔线**：全压纸，行距靠留白。觉得糊就加 0.5px 墨 8% 的底边线，别给行套卡片。
4. **只要夜间模式**：旧的深色主题已删，得重做一套深色 token，不能「切回去」。

## v0.6.2 不认识按钮 + 前缀搜索 + 添加时间排序 + 遮盖点按切换

四处小改动，**调度规则、箱位、选项判定一条没动**。

### 学习卡片：新增「不认识」

- 四个选项下面加一个全宽、描边次要样式的「不认识」按钮，和四个选项明显不是一类。
- 点它按**首次答错**记：降一箱、进当日重测，小结里算一次首次答错，然后直接进这个词的详情整页。
- 已经点错过选项的卡再点「不认识」：不重复记错，只进详情页。
- 答对后按钮自动隐藏；点错后按钮保留。

### 词库搜索：只匹配开头

- 我的词表、自加词、离线词典三处搜索都改成前缀匹配，不再匹配单词中间。
- 搜 `no` 不再出 indigenous / manoeuvre / autonomy / renovate / gastronomic；
  搜 `n` 不再出 transmit / conscious。
- 排序不变：精确命中仍排最前，其次前缀。

### 词库排序：新增「添加时间」

- 排序按钮从两态改成三态循环：原序 → 随机 → 添加时间 → 原序，文案和图标跟着变。
- 添加时间 = 最新加的排最前：820 词按序号倒序（820 → 1），自加词按加入时间倒序排在 820 词前面。
- 随机仍是点一次重排一次，不动数据库顺序。

### 词库列表：遮盖中文改点按切换

- 遮盖开着时点一下中文释义显示意思，再点同一处恢复遮盖，来回切换。
- 我的词表、自加词、离线词典三个列表行为一致。
- 点行内其他地方仍进详情页，两者不冲突。

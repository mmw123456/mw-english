## v0.6.9 预览版 · 玻璃洗干净 + 氛围活起来 + 顶部胶囊条

只改学习卡片这一屏（外加玻璃主题文件）。数据层、`app.dart`、外壳、其余页面零改动。

### 一、磨砂 6px → 1.5px，白 tint 5% → 2%

按 Apple Clear 的做法：玻璃不再整块上底色，存在感交给 **1px 迎光亮边 + 投影 + 背后的颜色**。

- 磨砂 `6 → 1.5px`，白 tint `5% → 2%`。整块板基本看不出有一层，只剩边缘那道斜光。
- 磨砂为 0 时不再开 `BackdropFilter`：小胶囊（顶栏、标签、箱数）直接跳过这层，一屏十块玻璃也不用付十次 `saveLayer`。
- **选中态 36% 白 tint、点错态 22% 粉、高光倍率、投影 `.20` / 选中 `.28` 一律没动。**

### 二、一处必须修的坑：投影把玻璃压灰了

`BoxDecoration` 的 `boxShadow` 会把 20% 黑**连形状内部一起涂**。以前 5% tint 盖得住，降到 2% 之后整块玻璃变成灰板（实测纸 `243 → 195`）。

改法：投影自己画 —— 画布先裁成「外框减去圆角矩形」，再画带 `maskFilter` 的模糊圆角矩形，内部一个像素都不碰。投影参数（`.20` / `.28`、`0 10 32` / `0 12 34`）完全不变，只是把它放回该在的位置。新增像素级用例守住这条：玻璃中心必须 ≥250。

### 三、字色对比实测 ≥4.5:1

按最差叠色算：纸 ← 某支氛围色 25% 峰值 ← 玻璃 2% 白 tint。

| 底色 | 墨 `#0B0C10` | 次要字（墨 70%） |
| --- | --- | --- |
| 橙 `#FF5A1F` | 13.9:1 | 5.4:1 |
| 粉 `#FF2E7E` | 12.7:1 | 6.1:1 |
| 绿 `#2BD9A0` | 15.2:1 | 6.7:1 |
| 紫 `#8B5CFF` | 13.1:1 | 6.2:1 |
| 蓝 `#2E4BFF` | 12.1:1 | 5.9:1 |

**次要字从 `#6B6E78` 换成墨 70%**：氛围一浓，原来的灰压在蓝斑上只有 3.1:1，不达标。用 alpha 形式（`0xB30B0C10`）而不是定值，让它跟着底一起变深，纸上是 `#515153`（7.4:1）。因为全部实测达标，**没有加局部磨砂** —— 加了反而破坏「不上底色」。

### 四、氛围五色 18%–25% + 慢漂移

- 五团光透明度 `9%–12% → 18%–25%`（橙 24 / 粉 22 / 绿 20 / 紫 25 / 蓝 18）。
- 一个控制器带五团，**24 秒一个来回**、`easeInOutSine`，各团相位与幅度不同（20–28px），所以是各漂各的，不是整体在晃。慢到不该抢注意力。
- 系统开「移除动画」时整层静止（低电量下的省事做法）。

### 五、顶部改成悬浮玻璃胶囊条

- AppBar 撤掉，换成一整条玻璃胶囊：**X、进度数字、书本图标全在里面**，胶囊浮在纸上（投影仍是 `.20`）。
- 胶囊下面一根 **2px 细进度线**，按 `1 / 28` 填充；`1 / 28` 用 13 / 700 的小字放进胶囊里。
- 「今日重测」「箱 1」做成两颗小标签胶囊，左右对齐，字号拉开（13 / 700 与 11 / 600）；胶囊条与题目之间留 34px，呼吸感。
- 仍是纸底 + 玻璃，没有引入新颜色。纸底是浅色，状态栏图标改成深色（`SystemUiOverlayStyle.dark`），否则没有 AppBar 帮忙，图标会白到看不见。

### 三个观感预期，先说在前面

- 玻璃现在几乎是「看不见的板」：只剩边缘一道光和底下一层影。这是 Clear 玻璃的正常样子，不是没做出来。
- 氛围比上一版明显浓了，屏幕下半部会有一片蓝紫。若觉得抢戏，先把蓝那团从 18% 降到 12%，别动字色。
- 一屏十块玻璃，其中七块带 1.5px 磨砂、三块不带。低端机若掉帧，把 `LiquidGlass.blur` 直接改成 0（一行），玻璃感不会明显变差。
